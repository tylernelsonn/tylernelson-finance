Welcome

This website performs common financial calculations used in investment analysis. Upload historical price data from Nasdaq.com for one or two stocks and a market benchmark, choose a date range, and the site calculates:

  • Risk and return measures: beta, CAPM (Jensen's) alpha, volatility and correlation
  • Performance measures: holding-period return, annualized return, excess return over the benchmark, Sharpe ratio and Treynor ratio
  • Time-series and cross-sectional analysis: returns over any date range, a side-by-side comparison of stocks, and a two-stock portfolio using weights you choose
  • Market and firm characteristics: market capitalization, P/E ratio, dividend yield and book-to-market ratio

Go to the Financial Analysis tab to begin. Sample data is preloaded so you can see how it works right away.

Methodology and Formulas

P = closing price, R = periodic (daily) return, n = number of return periods, N = periods per year (252 for daily data), T = length of the period in years, Rf = annual risk-free rate.

  • Periodic return: Rt = Pt / Pt−1 − 1
  • Holding-period return (HPR): Pend / Pstart − 1
  • Annualized return (geometric): (1 + HPR)1/T − 1, where T = calendar days ÷ 365.25
  • Volatility (annualized): σ = sample standard deviation of R × √N
  • Beta: β = Cov(Ri, Rm) / Var(Rm), the slope of a regression of the stock's returns on the market's returns
  • CAPM (Jensen's) alpha (annualized): α = [ mean(Ri − rf) − β × mean(Rm − rf) ] × N, where rf = Rf ÷ N is the risk-free rate per period
  • Correlation: ρ = Cov(Ri, Rj) / (σi σj)
  • Excess return over benchmark: annualized return of the asset − annualized return of the benchmark
  • Sharpe ratio: mean annual excess return over Rf ÷ annualized volatility = [ mean(R − rf) × N ] / σ
  • Treynor ratio: [ mean(R − rf) × N ] / β
  • Portfolio return: Rp,t = w1R1,t + w2R2,t, with w1 + w2 = 1 (weights are restored every period, i.e. rebalanced daily)
  • Market capitalization: share price × shares outstanding
  • P/E ratio: share price ÷ earnings per share (trailing 12 months)
  • Dividend yield: annual dividend per share ÷ share price
  • Book-to-market ratio: book value of equity ÷ market capitalization

Notes and Limitations

  • Nasdaq.com prices are closing prices that are not adjusted for dividends. Returns therefore measure price appreciation only and slightly understate total return for dividend-paying stocks. Prices are adjusted for stock splits.
  • Returns are calculated only on dates where every uploaded security has a price.
  • Sharpe, Treynor and alpha use the arithmetic mean of periodic returns (the standard textbook approach). The annualized return uses geometric compounding, so the two can differ slightly.
  • Annualizing results for periods shorter than one year can exaggerate them.

Financial Analysis – Inputs

How to get free data from Nasdaq.com:
  1. Go to nasdaq.com/market-activity/quotes/historical and search for a ticker (for example AAPL).
  2. On the stock's Historical Quotes page, choose a time range (1M, 6M, YTD, 1Y, 5Y or MAX, up to about 10 years).
  3. Click Download Data. A file named something like HistoricalData_1728...csv downloads.
  4. Repeat for your second stock (optional) and for the benchmark. Use SPY (the S&P 500 ETF) as the market benchmark. Choose the same time range for every file.
  5. Drag each file onto its box below, or click the box to browse. Then type the ticker in the name box, since Nasdaq's file names don't include it.
  6. Enter the risk-free rate (the current 3-month Treasury bill yield), pick a date range, and click Calculate.
